# 🤖 Telegram-бот для уведомлений о задачах из Notion

Бот автоматически синхронизируется с базой данных задач в **Notion**, отслеживает назначение задач и изменения их статуса, и отправляет персонализированные карточки задач исполнителям в **Telegram** с возможностью быстро менять статус («🚀 В работу», «✅ Выполнено») прямо из мессенджера.

---

## 🚀 Быстрый старт за 3 шага

### Шаг 1. Получение токена Telegram-бота
1. Откройте в Telegram [@BotFather](https://t.me/BotFather) и отправьте команду `/newbot`.
2. Введите имя бота и юзернейм (например, `my_notion_tasks_bot`).
3. Скопируйте полученный токен (вида `123456789:ABCdefGhI...`).

### Шаг 2. Создание интеграции в Notion
1. Перейдите на страницу [notion.so/my-integrations](https://www.notion.so/my-integrations).
2. Нажмите **«+ New integration»** (Создать интеграцию):
   - Укажите имя (например, `Telegram Tasks Notifier`).
   - Выберите связанное рабочее пространство (Workspace).
   - В правах (Capabilities) оставьте включенным чтение и запись контента (Read, Update).
3. Нажмите **Submit** и скопируйте **«Internal Integration Secret»** (начинается с `secret_...`).
4. **ВАЖНО! Подключите интеграцию к вашей базе Notion**:
   - Откройте в Notion вашу базу задач (`2d1bc62a-0c70-8158-9955-000398a16908`).
   - В правом верхнем углу нажмите на значок меню **`...`**.
   - Прокрутите вниз до **«Connections»** («Подключения») -> **«Connect to»** / **«Добавить подключение»**.
   - Выберите имя созданной интеграции и подтвердите доступ.

### Шаг 3. Заполнение настроек и запуск
1. Откройте файл `.env` в папке бота:
   ```env
   BOT_TOKEN=вставьте_токен_бота_от_BotFather
   NOTION_TOKEN=secret_вставьте_токен_интеграции_Notion
   NOTION_DATABASE_ID=2d1bc62a-0c70-8158-9955-000398a16908
   POLL_INTERVAL_SECONDS=60
   ADMIN_IDS=ваш_telegram_id
   ```
2. Проверьте подключение к Notion:
   Запустите файл **`check_notion.bat`** (или команду `.\.venv\Scripts\python test_notion_connection.py`).
   Скрипт покажет название вашей базы, колонки и список существующих задач.
3. Запустите бота:
   Дважды кликните по файлу **`run.bat`** (или выполните `.\.venv\Scripts\python main.py`).

## 👥 Как люди получают уведомления?

Бот поддерживает несколько гибких способов сопоставления:

1. **По Telegram Username (`@username`)**:
   - Если в Notion в поле исполнителя или в колонке `Telegram` указан `@никнейм` пользователя, бот найдет его автоматически, когда пользователь нажмет `/start`.
2. **Интерактивная привязка через бота**:
   - Пользователь запускает бота (`/start`) и нажимает кнопку **«🔗 Привязать Notion»**.
   - Бот загрузит список участников Notion Workspace, и пользователь выберет свой профиль одним нажатием.
3. **Ручная привязка администратором**:
   - Администратор может привязать пользователя командой в боте:
     `/link @telegram_username Имя_в_Notion`

## 📋 Возможности бота

- 🔔 **Мгновенные уведомления**: при назначении новой задачи бот присылает сообщение с названием, дедлайном, ссылкой и кнопками.
- 🔄 **Отслеживание изменений**: при смене статуса или переназначении исполнителя бот уведомляет сотрудников.
- ⏰ **Напоминания о дедлайнах**: автоматическое напоминание за 1 день и в день наступления срока сдачи.
- ⚡ **Управление из Telegram**: кнопки «🚀 В работу» и «✅ Выполнено» сразу обновляют статус задачи в базе Notion.
- 📂 **Команда `/my_tasks`**: просмотр всех своих активных незавершенных задач.
- ⚙️ **Админ-панель**: команды `/status`, `/users`, `/sync` для управления синхронизацией и пользователями.

```
├── run.bat                  # Скрипт запуска бота для Windows

├── requirements.txt         # Библиотеки Python (aiogram 3, notion-client, aiosqlite)

├── notion_service.py        # Клиент для работы с Notion API
├── scheduler.py             # Фоновый планировщик синхронизации
├── keyboards.py             # Инлайн-кнопки
├── test_notion_connection.py# Скрипт диагностики подключения к Notion
└── handlers/
    ├── common.py            # Обработчики команд пользователя (/start, /my_tasks)
    └── admin.py             # Обработчики админских команд (/status, /users, /sync)
```
